# Measurement and Property Contract

本契约定义跨材料体系复用的测量运行、数据产物、分析步骤和性能记录。具体仪器适配器只能增加条件化字段与验证规则，不能改变这里的证据、实体和溯源边界。

## 1. 对象边界

- `entity`：材料、批次、样品、试样、薄膜、器件、电极或电芯等可识别对象。
- `specimen snapshot`：测量时刻的实体状态；切割、抛光、涂覆、老化、充放电或环境暴露后视为新快照或新实体。
- `measurement_run`：一次具有确定目标实体、方法、配置、条件和数据产物的测量运行。
- `data_artifact`：原始、校正、处理、拟合或汇总数据文件；同一文件可被多个分析步骤引用，但不能混淆处理层级。
- `analysis_step`：把输入数据转成新数据或结果的可复现步骤。
- `property_record`：一个目标实体在明确条件下的一个被测量、报告或推导的量。

仪器与方法必须分开。相同仪器可以运行不同方法；相同方法可以由不同仪器实现。不要把品牌型号当成测量技术，也不要仅凭文件扩展名推断方法。

## 2. 必需谱系

性能记录应形成以下链条：

`entity/specimen snapshot -> measurement_run -> raw data artifact -> processing/analysis steps -> processed or fitted artifact -> property_record`

如果来源只报告最终值，允许缺少原始文件和分析步骤，但必须：

- 保留直接证据定位；
- 把缺失原始数据、校准或处理参数写入 `missing_information[]`；
- 不把可复现性状态标为完整；
- 不自行补齐常见仪器默认参数。

## 3. 测量运行

每个 `measurement_run` 至少记录：

- 稳定 ID、目标实体 ID、来源和证据；
- `method_raw` 与规范化的 `method_canonical`；
- `technique_family` 与可选 `technique_subtype`；
- 仪器身份：制造商、型号、仪器 ID、软件/固件版本，仅在来源支持时记录；
- 试样几何、安装、取向、测量位置和坐标系；
- 环境和控制变量：温度、压力、气氛、湿度、磁场、电场、应变、流量等；
- 激励或程序：扫描范围、速率、步长、保持时间、波形、循环、顺序；
- 校准、标准物质、空白、背景和校准有效期；
- 采集配置：探测器、分辨率、采样率、积分时间、增益或等价参数；
- 数据产物、处理链、质量状态、异常和限制。

设定值与实测值分开。程序包含多个步骤时保留有序步骤，不得压平成无顺序参数集合。

## 4. 数据产物与分析链

数据产物使用以下层级：

- `raw`：仪器直接输出，未做科学解释性变换；
- `calibrated`：完成仪器校准或物理量换算；
- `processed`：去噪、基线、平滑、归一化、重采样或分割后的数据；
- `fitted`：模型拟合结果、参数、残差和诊断；
- `aggregated`：跨重复、区域、循环或样品汇总的数据；
- `figure-derived`：从图像或曲线数字化得到的数据。

每个产物尽可能记录：路径或持久标识符、媒体类型、格式、大小、哈希、生成时间、生成软件、父产物 ID、证据和访问状态。哈希缺失不能通过文件名替代。

每个 `analysis_step` 记录：

- 输入与输出产物 ID；
- 操作类型和有序参数；
- 软件、版本、脚本或模型标识；
- 人工选择、裁剪区间、排除点和约束；
- 运行警告、失败和质量检查；
- 是否可复现以及阻碍复现的缺失项。

始终保存原始层。处理后曲线不能覆盖原始曲线；拟合优度不能替代残差或适用性检查。

## 5. 性能记录

每个 `property_record` 只绑定一个主要目标实体，并记录：

- `property_raw`：来源原文名称；
- `property_canonical`：受控规范名称；
- `measurand_definition`：被测量定义、算法窗口或判据；
- 原始值、原始单位、规范值、规范单位和值类型；
- 标量、区间、上/下限、分布、序列或张量分量；
- 方向、坐标系、取向和各向异性信息；
- 温度、压力、频率、场、速率、循环数、龄期等适用条件；
- 面积、质量、体积、活性物质量、几何尺寸等归一化基准；
- 测量运行 ID，或在无运行信息时记录缺失原因；
- `reported`、`derived`、`inferred` 或 `predicted` 的确定方式；
- 不确定度、重复数、分布统计、置信区间或检出限；
- 证据、适用范围、限制和有效性状态。

不同判据得到的同名量必须拆分。例如转变温度的 onset、midpoint、zero、峰值或外推值不能合并为单一 `Tc`。

## 6. 条件化必需字段

| 结果类型 | 缺失时必须报告的关键上下文 |
|---|---|
| 力学强度、疲劳、蠕变、断裂 | 试样几何和方向、表面状态、加载模式/速率/波形、温度环境、标准或方法 |
| 电学、磁学、热输运 | 接触/测量几何、方向、温度、场和扫描历史、几何换算 |
| 电化学与电池 | 电极/电芯层级、面积和载量、参比体系、程序步骤、电压或 SOC 窗口、温度、归一化基准 |
| 热分析 | 样品质量、坩埚/参比、气氛和流量、温度程序、循环、校准、结果判据 |
| 光谱 | 激发源、功率或通量、光斑/几何、分辨率、积分、背景/校正和拟合规则 |
| 显微和图像统计 | 制样、视场和位置、像素标尺、束流/探针条件、采样区域、分割和统计方法 |
| 衍射和散射 | 辐射源、波长、几何、扫描范围/步长、样品取向、背景、结构/峰模型和拟合诊断 |

这些字段是“结果存在时条件化必需”，不是每篇文献的全局必填项。

## 7. 派生值与不确定度

派生性能必须保存：

- 公式或算法标识；
- 输入记录 ID；
- 常数、假设、修正和单位变换；
- 传播后的不确定度，或无法传播的原因；
- 软件/脚本版本和输出产物；
- 与来源报告值的关系：复算一致、复算不一致、无法复算或仅来源报告。

模型预测单独标记 `predicted`，不得冒充测量值。相关性、拟合或机器学习重要性不自动构成因果机理。

## 8. 审计规则

1. 没有目标实体绑定的性能值无效。
2. 没有测量条件的数值不能自动与其他来源比较。
3. 原始值和规范值必须同时可追溯，禁止只保留换算后结果。
4. 单位、分母、面积定义、质量基准和几何换算不一致时，先判不可比。
5. 图中数字化值标为 `figure-derived`，保存图、坐标轴、数字化方法和误差来源。
6. 处理参数、拟合区间、背景和排除点是结果的一部分，不是可省略的实现细节。
7. 失败、无信号、低于检出限和被排除运行作为数据保留，不能静默删除。
8. 仪器生成的自动字段不等于已验证事实；记录来源和是否经人工/规则核验。
9. 未报告值保持缺失并说明影响，禁止填入“室温”“常压”“默认设置”等习惯值。
10. 每个高影响性能声明必须可回溯到证据、运行或明确的派生链。

## 9. 误差预算接口

`property_record.value.uncertainty` 只描述该值本身附带的不确定度，不等于完整 `error_budget`。完整预算另行记录：重复结构、误差分量、共同统计基础、协方差假设、综合不确定度、未分配变异，以及它与偏差效应的关系。

- 同一测量重复、同批不同样品、不同批次和不同设备必须保留层级，不能先平均后丢失结构；
- 分析窗口、拟合、分割和等效模型的不确定度属于数据处理/模型分量；
- 外推误差单独记录，不能与测量噪声合并后称“实验误差”；
- 只有共享统计基础的分量才允许计算贡献比例；
- 当数据不足时，保留定性误差树和缺失实验设计，不生成伪精确总不确定度。
