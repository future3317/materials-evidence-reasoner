## 数据口径说明（重要）

1. **Kimi-K2.7-Code** 与 **GLM-5.2** 均采用 0–100 加权分制，可并列对比；但注意：Kimi 使用官方权重（30/20/15/15/10/10），GLM 报告内权重被改动过（30/25/15/10/10/10），**绝对分差可对比，维度级细分需谨慎**。
2. **GPT-5.6-luna** 采用另一套 rubric 覆盖率指标（单次运行，0/94/100% 制），与前两者的 0–100 加权分**不可直接数值比较**，单列呈现。
3. 此前汇总中「来源待核查」的 Baseline 59 / Skill 75 / +16 / +27.1% 一组数字，现已确认来源为 **Kimi-K2.7-Code**，与 GLM 的 58 / 78 / +20 并不冲突——是两个不同模型的各自结果。

## 给项目展示的三句话结论

1. **跨模型复现：** Kimi-K2.7-Code（+16 分，+27.1%）与 GLM-5.2（+20 分，+34.5%）上 Skill 均显著提升，GPT-5.6-luna 的 rubric 口径结论方向一致——Skill 有效且**不绑定特定模型**。
2. **增益结构清晰：** 最大增益稳定落在「证据可追溯」与「结构完整性」——Skill 不是让模型更聪明，而是让输出**可信、可交接、可机读**。
3. **诚实披露：** GLM 自评如实报告了两个 −2 分退步维度；Skill 代价为约 2 倍推理时间。待办：统一两模型的六维度权重口径，以便更严格的跨模型维度级对比。
