# Coulombic efficiency 重复测量：使用 Skill 组行动优先报告

## 一句话结论

在唯一输入 `error-budget-demo.csv` 的 27 个观测中，当前可识别的主要变异来源是批次间层级（batch-between，描述性方差占比 89.1%）；但材料身份、批次谱系、测量协议和仪器元数据缺失，所以只能支持“批次标签相关的变异值得优先验证”，不能支持“材料/工艺导致了 CE 差异”或外部优劣/复现结论。[E-CSV-META][E-ANALYSIS-EB]

## 现在该做什么

1. 先补齐 B1/B2/B3 的材料与工艺谱系，以及每次运行的仪器、通道、操作者、日期、校准和分析版本；否则不把 batch-between 升级为材料机制。[IG-CE-1][IG-CE-2]
2. 在锁定 CE 定义、窗口、单位和归一化分母后，按现有 3 批次 × 3 样品 × 3 重复结构做一次运行顺序随机化的配对重测，并加入现有 SOP 定义的参考控制。[V-CE-01]
3. 只按预先规则判定：固定测量系统后批次差异仍复现，才保留 H-CE-1；差异随仪器/操作者/日期/处理版本消失，优先 H-CE-2；协议或定义无法锁定，则停止材料归因。[V-CE-01]

## 误差预算与可支持结论

`analyze_error_budget.py` 使用平衡嵌套结构 `repeat → sample → batch` 做 descriptive method-of-moments 方差分解。共同方差基础上，batch-between 最大（0.104679 个百分点²，89.1%），sample-within-batch 次之（0.010969 个百分点²，9.3%），within-sample repeatability 最小（0.001804 个百分点²，1.5%）。这些比例只回答“当前模型下哪个方差层级最大”，不回答“哪个物理原因解释了性能差异多少”。[EB-REAL-1][E-ANALYSIS-EB]

脚本给出的 `2×SD = 0.5810` 个百分点，只能作为描述性扩展散布；由于没有独立决策效应或规格限值，效应—不确定度关系保持 `unknown`。未分配为 0.0 不是“校准、环境、处理和模型误差不存在”的证据；这些因素未被交叉设计识别。[EB-REAL-1]

因此当前可以支持：

- 这 27 个数值不是以短期重复测量散布为主，而是以批次层级分离为主；
- B1/B2/B3 的 CE 均值在本数据表内有明显的描述性差异；
- 下一步优先级应是测量系统/协议审计与随机化配对重测，而不是直接优化材料参数。

当前不能支持：

- 材料组成、结构、界面或工艺导致了 batch-between 变异；
- B1/B2/B3 相对于文献、规格或目标“更好/更差”；
- 已完成复现、失败归因或跨材料迁移；
- 89.1% 可以直接解释 CE 性能差异的 89.1%。

## 竞争解释与最小验证实验

| 假设 | 当前状态 | 独有预测 / 反证 |
|---|---|---|
| H-CE-1 批次相关因素主导 | plausible | 锁定测量系统后批次差异仍复现；若差异消失或 B1–B3 只是日期/仪器标签，则反证 |
| H-CE-2 测量系统/协议与批次共变 | plausible | 同一仪器/操作者/分析版本、随机化顺序和参考控制下差异缩小；若元数据一致且仍复现则削弱 |
| H-CE-3 同批样品异质性 | speculative | 同批样品均值在重测后仍稳定且超过 repeatability；若随通道/顺序消失则反证 |
| H-CE-4 短期重复性主导 | 当前模型下 refuted | 当前 repeatability 仅 1.5%；若锁定系统后重复散布达到批次均值范围则重新打开 |

最小集只有一项：[V-CE-01]。它复用现有 3×3×3 分层，锁定 CE 公式/窗口/分母，随机化 batch/sample 运行顺序，记录仪器/操作者/日期/校准/分析版本，并使用 SOP 已定义的参考控制。该设计同时覆盖 [IG-CE-2]、[IG-CE-3]、[IG-CE-4] 和四个竞争假设。[SET-CE-MIN-01]

停止规则：参考控制不合格、关键定义/元数据不能锁定或无法随机化时，停止材料归因；固定系统后批次差异不超过重复性范围时，停止 H-CE-1 升级；成本或样品消耗超过可获得的决策价值时，接受 `inconclusive`。[V-CE-01]
